# Eswar Sai Teja — Personal e-Portfolio

A responsive, creative-style personal portfolio built with React and Vite.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the integrated terminal and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. Import that repository in Vercel.
3. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

## Personalisation notes

- Replace `public/images/eswar-profile.jpg` to change the portrait.
- Update social links, email and profile copy in `src/main.jsx`.
- Project cards marked "DETAILS SOON" currently have no public repository/demo URL. Add a URL only after confirming the correct project repository.
- The included resume is a DOCX attachment; replace it with a PDF when you have a final PDF version for a more convenient browser download.
